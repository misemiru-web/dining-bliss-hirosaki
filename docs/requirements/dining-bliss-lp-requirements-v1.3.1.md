## PMレビューを反映した重要方針

1. **主目的を「予約検討」に一本化する。** Instagram・電話・地図は副導線。
2. **予約先は第三者掲載ページであるため、正式な店舗指定予約URLとは扱わない。**
3. **セクションを増やさず、料理 → 店の使い方 → 空間 → 情報 → 予約の順にする。**
4. **営業サンプルの完成度を上げるため、Hero・料理写真・店舗情報・CTAに工数を集中する。**
5. **最新性を確認できない価格・季節メニュー・「人気商品」はサンプル本文に固定表示しない。**

# 4. 仮説・未確認事項

## 4-1. 仮説

以下はLP設計上の仮説であり、店舗の公式説明ではない。

- 「料理写真を見て店を知り、その後に雰囲気・営業時間・予約方法を確認する」閲覧行動と相性がよい
- ランチ目的とディナー目的の双方に情報整理価値がある
- ダークトーンの空間写真と鮮やかな料理写真を対比させると店舗らしさが伝わりやすい
- Instagram上に料理・空間・営業情報が分散しているため、1ページに整理する価値がある
- 豪華な演出より、写真の大きさ・余白・タイポグラフィを整える方が店舗写真の魅力を生かしやすい

## 4-2. 未確認

- 一番人気の商品
- 店主が最も推したい看板料理
- 正式な店舗コンセプト
- 実際の主要客層・年齢層
- デート・一人利用・家族利用等の比率
- 現在提供中の全メニュー
- 各料理の最新価格
- ランチ終了時刻の14:00 / 14:30差異
- L.O.時刻
- 電話番号の正式確認
- ヒトサラを正式予約窓口として今後も使用するか
- Instagram投稿写真のうち正式サイトにも継続利用してよい範囲

# 5. 店舗分析

## 5-1. 特徴

1. **料理写真の訴求力が高い**
   - ソースの艶、肉の断面、揚げ物の質感など、料理そのものが視覚的に強い。

2. **ランチとディナーの両面が見える**
   - オムライス・パスタ等のランチ系写真に加え、肉料理、前菜、酒類、デザートの写真がある。

3. **料理写真と空間写真のコントラスト**
   - 料理は赤・黄・緑など鮮やか。
   - 店内はチャコール、木、暖色照明中心。

4. **カウンターとテーブルの両方が確認できる**
   - 来店前の空間理解につながる。

5. **外観の識別性がある**
   - ダークな外壁と「Bliss」の丸型サインが確認できる。

## 5-2. LP上の強み

- 大きな料理写真を主役にできる素材量
- 昼夜の利用イメージを1ページで整理できる
- Instagramでは分散している店舗情報をまとめられる
- 店内・外観写真により、来店前の不安を減らせる
- 予約条件を明確に提示できる

## 5-3. 提供価値

### 機能的価値
- 料理、営業時間、定休日、予約条件、アクセスを一度に確認できる
- 予約ページへ迷わず進める
- 入店前に店内・外観を確認できる

### 情緒的価値【仮説】
- 料理の温度感と店内の落ち着いた空気感を写真で感じられる
- 「どんな店か分からない」という初回来店前の不安を抑えられる

## 5-4. 差別化仮説

競合調査を行っていないため「他店より優れている」とは表現しない。  
LPでは**「料理写真の強さ」「昼夜双方の料理」「ダークな空間と温かい照明」**という店舗自身の視覚資産を差別化要素として整理する。

# 7. LP戦略

## 7-1. 主目的

**予約検討の促進**

直接的な予約完了数を保証するものではなく、営業サンプルでは「予約導線が明確な完成イメージ」を店舗に見せることを目的とする。

## 7-2. 副目的

- 初回来店前の情報確認
- Instagramでは把握しづらい情報の整理
- 店舗の料理・空間の魅力を1ページで伝える

## 7-3. CV

主CV：
- ヒトサラ掲載予約ページへの遷移

副CV：
- Instagramプロフィールへの遷移
- Googleマップ等の地図への遷移
- 電話発信

## 7-4. 課題仮説

> Instagramには料理・店内・営業案内が複数投稿に分散しているため、初回来店者が「料理 → 雰囲気 → 営業情報 → 予約」を1ページで確認できるサイトには情報整理上の価値がある。

## 7-5. 情報設計方針

**写真で惹く → 店の内容を理解 → 昼夜の選択肢 → 空間確認 → 営業情報 → 予約**

不要なStory、口コミ、FAQ、Newsは追加しない。

# 8. LP・デザインコンセプト

## 8-1. コンセプト

### **FOOD FIRST, WARM AFTER DARK**

料理を最も強く見せ、ダークな空間と暖色照明でDining Blissの夜の雰囲気を補完する。

これは公式コピーではなく**デザインコンセプト**。

## 8-2. メインメッセージ

仮コピー：

### **昼も、夜も。Blissのひと皿を。**

サブコピー：

**ランチからディナーまで楽しめる、dining Bliss。**

### コピー判断

- 店舗名・昼夜営業という確認可能な範囲に寄せる
- 「絶品」「人気No.1」「本格」「最高」「隠れ家」等を安易に使わない
- 公式投稿で個別料理に使われた表現を、店舗全体の恒久コピーへ自動転用しない

## 8-3. ブランドトーン

- 大人っぽい
- 食欲を刺激する
- 気取りすぎない
- 写真を主役にする
- 広告感より店舗感

## 8-4. 配色【仮指定】

提示された旧LP画像の**色使いのみ**を参考にした仮配色。  
文章、構成、レイアウト、CTA、タイポグラフィ方針など、色以外の要件は変更しない。  
以下は正式ブランドカラーではなく、営業サンプル用のデザイントークン。

| Role | HEX | 用途 |
| --- | --- | --- |
| Warm Ivory / Main Background | `#F5F0E8` | 明るいセクション、Heroテキスト面 |
| Charcoal / Dark Background | `#211F1C` | Dinner、Atmosphere補助、Footer |
| Deep Burgundy / Primary Accent | `#7A2E2A` | Primary CTA、Reservation背景、小さな強調 |
| Dark Text | `#24211E` | 生成り背景の見出し・本文 |
| Light Text | `#F5F0E8` | チャコール・バーガンディ背景の文字 |
| Muted Text | `#7D756D` | 本文補助、注記 |
| Warm Gold / Secondary Accent | `#D2B78A` | 英字ラベル、数字等のごく小さなアクセント |
| Light Border | `#D8CFC3` | 生成り背景上の罫線 |
| Dark Border | `rgba(245,240,232,.22)` | ダーク背景上の罫線 |

### 配色比率の目安

- Warm Ivory：50〜60%
- Charcoal：20〜30%
- Deep Burgundy：10〜15%
- Warm Gold：5%未満

### 配色上の注意

- 提示画像から参考にするのは**色の関係性のみ**とし、旧LPの文章、構成、装飾、レイアウトは継承しない。
- Deep BurgundyはCTAとReservationなど限られた箇所に使用し、ページ全体を赤くしない。
- Warm Goldは補助色。大きな面積には使用しない。
- 料理写真そのものの色を、このパレットへ無理に寄せて加工しない。
- **赤い皿＝正式ブランドカラーとは断定しない。**

## 8-5. Typography

### 推奨方向
- 日本語：可読性の高いゴシック
- 英字：静かなSerifを小見出し・店名補助に限定
- 本文で英字を過剰利用しない
- 手書き風、昭和風、ヴィンテージ加工フォントは使用しない

### 実装候補
- Japanese：Noto Sans JP 相当
- English accent：Cormorant Garamond 相当

正式ロゴデータがない場合、**独自の偽ロゴを作らず `dining Bliss` をテキスト表示**する。

## 8-6. UI

- カードを並べすぎない
- 角丸 12〜20px 程度を上限
- 強い影は使わない
- 1pxの罫線、余白、写真サイズ差でリズムを作る
- CTAは塗りボタン1種類を主役にする
- 副CTAはoutline / text link
- 写真上の文字は必要最低限

## 8-7. Layout

### Desktop
- 最大コンテンツ幅：おおむね 1180〜1240px
- Hero：**左テキスト 40〜45% / 右料理写真 55〜60%** のsplit構成を第一案
- Food：1枚大 + 2枚小のeditorial grid
- Atmosphere：横長店内写真 + 補助写真

### Mobile
- 左右余白：20〜24px
- Hero：料理写真を上または背景全面、コピーとCTAを1画面内に収める
- 料理は小型カード化せず縦に大きく見せる
- 情報欄は完全縦積み
